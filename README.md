# OrderNest 🎫

A colorful web app for tracking your online orders, warranty expiry dates, and return deadlines — all in one place.

## What it does

- **Add orders** with product name, store, price, category, order date, warranty end date, and return deadline
- **Color-coded status** — instantly see what's safe (green), ending soon (amber), or expired (red)
- **Gmail receipt links** — save a link back to the original order confirmation email
- **Gmail sync (demo)** — simulates auto-importing orders from your inbox, with duplicate detection
- **Search, filter & sort** by product, store, category, or deadline
- **Archive** old orders instead of deleting them
- **Dark mode**
- **Export to CSV**
- Everything saves automatically — no login required
